# 4. Apple Search Ads — starter plan  *(best first paid channel: cheap + high intent)*

People searching the App Store already want an app — you're just making sure they find yours. Set up at **searchads.apple.com** (start with **Apple Search Ads Basic**, or Advanced for more control).

## Structure (Advanced)
- **Campaign A — "Discovery" (Search Match ON):** let Apple auto-match searches; cheap way to find winning keywords.
- **Campaign B — "Exact keywords":** bid on the terms below as *exact match*.

## Keywords to bid on
```
garden planner, vegetable garden, gardening app, when to plant,
companion planting, plant care, raised bed, garden layout,
harvest calendar, plant identifier, veggie garden, grow vegetables
```

## Budget & bids (starting point)
- **Daily budget:** $10/day (~$300/mo) to start — enough to learn, small enough to be safe.
- **Default max CPT (cost-per-tap) bid:** $0.50–$1.00; raise winners, cut losers.
- **Target:** watch **cost-per-install (CPA)**. Under ~$2–3 per install is healthy for a free app; pause anything way above.

## The 2-week routine
1. Launch both campaigns, let them run 3–4 days untouched (Apple needs data).
2. Move keywords that convert cheaply from Discovery → the Exact campaign, raise their bids.
3. Add converting search terms as new exact keywords; add wasteful ones as **negative keywords**.
4. Repeat weekly. Scale budget only on keywords that hit your CPA.
