## When

Post the Instagram carousel now. Pin the same day, then re-pin `pin.png` to a
second board a few days later - normal on Pinterest, not spam.

If you film the Reel (hold a real sick leaf, scan it on screen), post it 3-4
days after this carousel rather than the same day.
